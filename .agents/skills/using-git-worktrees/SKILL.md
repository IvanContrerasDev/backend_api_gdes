# Skill apagada por el harness

En este repo NO se usa `using-git-worktrees`: crear worktrees, branches o commits son mutaciones git, y acá **ninguna mutación git se hace sin confirmación explícita del humano**.

- Trabajás en la branch que el leader indica en el prompt de despacho.
- Si creés que hace falta un worktree o una branch nueva, lo proponés al leader y el humano decide.
